Сервер каталогів

Необов’язковий, запускається у вас: діліться папкою каталогів зі свого комп’ютера — локальною мережею або через інтернет.

  • Microsoft Store (Windows)
  • Snap Store (Linux)
  • Інші варіанти завантаження (macOS, Chromebook, напряму)

Усе будується навколо ваших файлів каталогу

  • Безкоштовно, без підписки Застосунки безкоштовні та з відкритим вихідним кодом (MIT). Без облікових записів і тарифів.
  • Каталог — це один файл Зображення, точки й дані зберігаються разом в одному файлі .ecatm на вашому пристрої. Він нікуди не йде, доки ви самі ним не поділитеся.
  • Фотографії та схеми Ставте точки на будь-яке зображення — фотографію меблів, схему запчастин, анатомічну таблицю.
  • Посилання на ваш власний магазин Спрямовуйте позиції в будь-який інтернет-магазин, яким ви вже користуєтеся. Ніякого нашого маркетплейсу чи оформлення замовлення посередині немає.
  • Працює без мережі після першого запуску Після першого запуску на комп’ютері, планшеті або телефоні застосунки зберігаються в браузері та продовжують працювати без підключення.
  • Спільне редагування — лише якщо воно вам потрібне Для спільного редагування потрібен необов’язковий сервер спільної роботи, який запускається у вас. Усе інше працює без нього.

Завантаження сервера спільної роботи

Запустіть сервер спільної роботи в себе, щоб редагувати каталог разом з іншими людьми в реальному часі. Щоб створювати чи переглядати каталог самостійно, він не потрібен.

Windows: завантажити з Microsoft Store (або пряме завантаження, файл .exe)

Linux: завантажити зі Snap Store (Ubuntu App Center, або пряме завантаження для інших дистрибутивів)

macOS: (потрібна macOS 13 або новіша) пряме завантаження (Apple Silicon, або Intel) — розпакуйте архів, а потім на сторінці релізу знайдіть однорядкову команду для Терміналу, яка потрібна під час першого запуску

Chromebook (Linux/Crostini): пряме завантаження, файл .deb — інструкцію з налаштування дивіться на сторінці релізу
